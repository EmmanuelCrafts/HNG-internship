# Profile Card — Frontend Wizards Stage 0

## Overview
This project is a **clean, minimal, and responsive Profile Card** built using **HTML, CSS, and vanilla JavaScript**.  
It demonstrates **semantic HTML, accessibility, keyboard navigation, and basic JavaScript** by showing the current time in milliseconds.

The card includes:
- **Name**  
- **Short biography**  
- **Avatar image**  
- **Current time (in milliseconds)**  
- **Social media links** (Twitter, GitHub, LinkedIn, Instagram)  
- **Hobbies** and **Dislikes** lists  

All visible elements include the required `data-testid` attributes for automated testing.

## Features
- Semantic HTML (`<article>`, `<figure>`, `<nav>`, `<section>`, `<ul>`, `<li>`)  
- Keyboard accessible links with visible focus styles  
- Responsive design for mobile, tablet, and desktop  
- Avatar image with descriptive alt text  
- Social links open in a new tab with `rel="noopener noreferrer"`  
- Live time display in milliseconds (`Date.now()`) updated every second
